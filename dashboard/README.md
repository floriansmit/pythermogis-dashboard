# Dashboard application

From the repository root, run:

```powershell
python dashboard/install_dashboard.py
python dashboard/run_dashboard.py
```

Both scripts resolve their supporting files relative to their own location, so
the repository can be placed in any directory.

The complete installation, input, and workflow documentation is in the
[repository README](../README.md) and [user guide](../docs/USER_GUIDE.md).
